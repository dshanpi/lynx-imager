# LYNX Imager 桌面工作台设计规范

## 从设备到任务

LYNX Imager 默认打开「基础烧录」。熟悉板卡的用户在「高级烧录」内选择设备并进入工具；需要外部 AI 的用户在「连接 AI」内取得对应端点。三个入口共用一个应用标题栏。桌面框架负责窗口控制，内容区负责设备与任务。

| 工作区 | 左栏 | 主区 | 下一步 |
| --- | --- | --- | --- |
| 基础烧录 | 五个可见步骤与当前步骤 | 板型搜索与厂商筛选 → 镜像及所需 Loader → 目标接口、模式与介质 → 写入摘要及结果 | 选择有效才可前进；最后一步明确目标与覆盖范围 |
| 高级烧录 | 已保存设备、搜索、单一选中行 | 当前设备工具栏，下面切换概览、SSH、串口、固件烧录与文件传输 | 打开所需工具后直接操作当前设备 |
| 连接 AI | 现有通道或配置项 | Windows 本地 MCP、远端 SDK 隧道的地址、独立验证结果与客户端配置 | 复制当前端点或可用命令，结果在对应控件旁反馈 |

效果图左栏依次显示「选择开发板」「选择镜像」「配置接口」「确认烧录」「写入与校验」。现有产品的四项业务步骤为「选择板子」「选择系统」「配置接口」「烧写系统」。设计将第四步的确认页和执行结果页分开显示，对应同一笔任务。返回确认页不能重复提交已在执行的任务。

设备设置仍从当前设备进入。切换顶层工作区时保留选择；设备切换后各面板绑定新设备，进行中的任务继续显示其原始目标。设备列表与向导步骤各自使用同一个左栏位置。

## 布局与尺寸

按桌面逻辑像素设计，桌面缩放交给系统。尺寸令牌记录于同目录的 `tokens.json` 和 `tokens.css`。

| 区域 | 基准 | 内容和对齐 |
| --- | --- | --- |
| 应用导航 | 高 44 px | 品牌与三个工作区同一基线；当前工作区使用品牌蓝指示线。原生窗口框架的非客户区单独计算 |
| 左栏 | 宽 208 px | 左栏标题左对齐，「新增」在标题右侧；搜索框占下一行，列表从搜索框下方开始。三者共用 16 px 起始线，选中行左侧为 2 px 品牌蓝指示线。列表内部独立滚动 |
| 设备上下文 | 高 40 px | 左侧设备名、型号或目标地址，右侧设备设置与可用操作；此栏在选定设备后出现 |
| 工具标签 | 高 36 px | 当前任务加下划线；键盘可切换。所属设备在上方持续可见 |
| 内容 | 横向内边距 16 px | 属性名、表头、正文和日志共用列起点；区段间隔 16 或 24 px |
| 表格、输入、按钮 | 高 32 px | 默认数据行 32 px。单行数字采用等宽数字，同列数字与单位对齐；多行报错自然增高 |
| 向导操作区 | 高 52 px | 当前选择摘要靠左，上一步与本步唯一主操作靠右；正文可单独滚动 |
| 应用状态栏 | 高 24 px | 当前目标、活动任务或连接摘要；使用来自同一次采集的值 |
| 控件 | 4 px 圆角、16 px 图标 | 图标按钮有可访问名称与可见焦点，点击区域至少 24 × 24 px。键盘环宽 2 px |

常用间距为 4、8、12、16、24 px。正文 14 px，辅助信息 12 px，区段标题 16 px，页面标题 20 px。常规、强调和标题字重依次为 400、500、600。界面使用随系统提供的西文与中文无衬线字体，串口名、地址、哈希和日志使用本地等宽字体。

**窗口适配。** 以桌面配置的 1280 × 768 为默认验收尺寸，也核对最小 1090 × 720、1440 × 900 和 1920 × 1080。宽窗口优先给终端、日志和属性值；窄窗口先把属性与监控从两列改成上下排列，再将次要工具动作移入具名菜单。长路径可换行或横向滚动，详情和复制仍提供完整值。长错误在正文内展开。默认和最小尺寸均应在首屏看到当前目标、工具入口和下一步操作。

## 高级烧录的工作面

| 区域 | 信息层级与状态 |
| --- | --- |
| 设备列表 | 一行显示名称与状态标记，辅助行可显示型号或接口。选中行使用底纹及左侧 2 px 指示线；在线、离线与占用都带文字 |
| 概览 | CPU、内存、根分区与温度排成一行摘要，显示单位和采样时间；空间不足就换行。没有采集值显示「未采集」 |
| 属性与接口 | 使用名称／值对，关联设备的 USB、串口、ADB、SSH 可分别查看状态。某接口断开只更新该接口 |
| 运行监控 | 共用百分比纵轴时，CPU、内存都以百分比显示。双曲线直接标记名称与单位，实线和虚线对应图例；显示时间范围、最近采样时刻和可读取的数值。缺失采样处断线 |
| SSH、串口终端 | 连接参数、连接与断开操作位于工具栏，终端占剩余空间。输出可选择复制；提供现有的滚动、清屏与导出操作。长日志只滚动终端 |
| ADB 文件传输 | 同一行核对本地与设备路径、传输方向，再执行发送或接收。在同一任务行显示字节数、进度和错误原因。离线时给出重新检测入口 |
| 固件烧录 | 核对板型、介质、镜像、Loader 和接口。结果按写入、校验、重启与启动验证分别记录；证据取自后端。只有确认了启动证据，才可以显示启动通过 |

诊断失败就地显示错误、相关设备与可执行的下一步。尚无设备时只提供添加或检测；任务执行中保留目标和进度；每个复选框、选择框与复制按钮显示自己影响的对象。

## 从原界面迁移

| 原界面中遇到的问题 | 本次设计决定 | 验收时看哪里 |
| --- | --- | --- |
| 顶栏、设备动作和标签都有大块选中色 | 顶部只切换工作区，第二层指明设备，工具名称在第三层 | 工具切换前后都能直接读到同一目标设备 |
| 监控四张独立卡片占满一屏上半部 | 将 CPU、内存、磁盘、温度并为一行，旁边标采样时间 | 1280 × 768 首屏同时看得到属性和监控内容 |
| 接口属性、ADB 操作和监控紧挨成堆 | 区分概览、终端、固件和传输工作面，属性按行对齐 | 从设备列表进入传输，能在同一工作面核对路径、方向与结果 |
| 侧栏、标签与状态重复显示绿色或蓝色 | 浅蓝底和边线指示选择，实心蓝按钮执行动作，局部状态带文字 | 灰度查看仍能判断选中行、当前任务、离线或错误 |
| 大屏伸展卡片，小屏主要内容被挤出 | 指标保持行高，宽度留给图表与路径；窄屏改为上下排列 | 最小窗口键盘遍历时当前焦点、操作区和结果都可见 |

## 样例与真实数据的对应

| 效果图中的内容 | 接入现有产品时的数据来源 |
| --- | --- |
| 型号、厂商、介质与 Loader 提示 | `ImagerPage.tsx` 内的板型预设；兼容的已保存目标来自 `workbench_list_devices`。预设本身只说明适配能力 |
| 设备 CPU、内存、根分区、温度与采样时间 | `workbench_linux_device_overview` 返回当前 `deviceId` 的快照。使用返回的 `collectedAtMs`；内存与根分区用总量、可用量推算占用率。历史曲线须取自该设备的逐次采样，只有单次采样就显示当前值 |
| 烧录阶段与进度 | `workbench_start_flash` 返回任务 ID；只处理与该 ID 匹配的 `workbench-task-event`。校验、重启和启动各自使用实际结果，缺少阶段证据时显示「未验证」或「未执行」 |
| 本地 MCP、远端隧道和可复制配置 | 现有 `localMcpConnection`、`remoteMcpConnection` 分别用当前本机服务和远端隧道的状态构建；客户端片段由 `buildMcpClientConfig` 生成 |
| 模板中的曲线、进度、日志或连接地址 | 均为显式标注的样例，只用于检查布局。屏幕效果图本身无法证明通信、烧录或启动通过 |

## 颜色、状态和图表

默认浅色为 **LYNX - Light**。设置中的主题名、白色面板、深蓝文字、品牌蓝和焦点光晕取自原版 LYNX。对应深色主题为 **LYNX - Dark**。基础色来自 [原版主题表](../../src/Themes/configs/lynx.json)，选择态、终端与焦点光晕见 [原版 CSS 令牌](../../src/Themes/tokens.css)。原设置使用主题名和变体名组成显示名称。截图中选项的系统高亮由桌面环境绘制。

Color System 用于检查浅深主题的对比度与图表辨识度。主按钮与小字号提示分别选取能在对应表面读清的色阶。工程中的角色定义见 [tokens.json](tokens.json)，CSS 变量见 [tokens.css](tokens.css)。

| 角色 | LYNX - Light | LYNX - Dark | 使用位置 |
| --- | --- | --- | --- |
| 窗口背景／内容表面 | #F5F8FC ／ #FFFFFF | #08090B ／ #111316 | 窗口衬底与设置白面板；设备列表使用内容表面 |
| 正文／辅助字 | #0D1830 ／ #5B6B82 | #F0F2F5 ／ #A8AFB8 | 正文使用原色；辅助字同时覆盖选中行 |
| 品牌蓝／选中底色 | #087FF5 ／ #E6F2FF | #2F8CFF ／ #1B2027 | 品牌标记、导航指示线；列表选择另带底纹和指示线 |
| 边框／细分隔 | #D9E3EF ／ #E5EBF2 | #25282D ／ #1C1F23 | 面板边界与属性行分隔；关键输入另用清晰边界 |
| 主按钮／按钮文字 | #006DDE ／ #FFFFFF | #2F8CFF ／ #050607 | 浅色以原主题悬停蓝承载白色小字；深色采用原主题按钮配对 |
| 键盘焦点／外侧光晕 | #087FF5 ／ #CEE5FD | #2F8CFF ／ #193253 | 品牌蓝焦点线外叠原侧光晕；光晕色值按原透明度在面板上合成 |
| 成功／警告／错误标记 | #16A34A ／ #D97706 ／ #DC2626 | #35C46A ／ #F2AD4B ／ #FF5F69 | 保留原版状态色并配图标与文字 |
| 成功／警告／错误文字 | #137942 ／ #9C5B13 ／ #D22527 | #35C46A ／ #F2AD4B ／ #FF5F69 | 小字用对比充分的同色系色阶 |
| CPU／内存曲线 | #087FF5 ／ #64748B | #2F8CFF ／ #A8AFB8 | CPU 用品牌蓝实线，内存用原版辅助色虚线，分别配文字图例 |
| 终端背景／文字 | #0B1422 ／ #D5DEEA | #030405 ／ #E2E6EB | 串口与 SSH 共用原版终端配色 |

以实际颜色计算，原版浅色品牌蓝配白字为 3.91∶1。白字小按钮沿用原版悬停蓝 #006DDE，可达 4.95∶1；深色原版按钮为 6.10∶1。浅色原版 #64748B 在白面板为 4.76∶1，但在选中行为 4.19∶1。跨表面的辅助文字和状态文字从原色向正文色按 5% 递进，采用在背景、侧栏、内容面、选中行与次级底色达到 4.5∶1 的首个色阶。控件边界按同一方法取达到 3∶1 的首个色阶。

## 交互与验收

- [ ] 仅用键盘完成选择板型、选镜像、配置接口、查看确认摘要与返回。顶部工作区和工具标签的策略一致；对话框接管焦点，关闭后焦点回到触发项。危险操作不能由进入对话框时的默认回车意外触发。
- [ ] 切换两个设备并检查终端、传输任务、固件摘要和底栏显示的目标。运行中的操作在切换视图后保留其真实目标。按钮与结果使用同一动作名。
- [ ] 截取默认与最小窗口，检查栏高、列表起线、表格列、按钮基线和底栏。增大系统文字后，标题不盖住工具入口，长路径、错误和哈希仍能取得全文。保留触发控件的完整焦点环。
- [ ] 分别查看空列表、未绑定、连接中、在线、断连、写入中、失败和成功。不能采集遥测的设备显示原因或可用入口，采集失败保留上次成功采样的时间。
- [ ] 浅色和深色分别计算正文、辅助字、状态字和主按钮文字的对比度，至少 4.5∶1；可操作边界、选中指示线、焦点和曲线相对其表面至少 3∶1。颜色与文字、线型或图标一起表达含义。开启系统高对比度和减少动画后复核，进度与日志仍可读。
- [ ] 在 Windows 与 Ubuntu 原生应用中复核系统字体、快捷键、焦点与缩放。预览图采用明示的样例数据，发布验收记录注明实际应用平台、窗口尺寸、主题与已运行的操作。
