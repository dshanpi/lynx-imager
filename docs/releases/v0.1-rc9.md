# LYNX Imager v0.1-rc9 · macOS 紧凑型号列表

适用于 **macOS 26.0+、Apple Silicon arm64**，应用版本 `0.1.0-rc.9`。本次为手动安装预发行版，使用 ad-hoc 签名，未 Apple Developer ID 签名和公证，不进入 macOS OTA。

## 更新内容

- 将大块芯片型号卡片改为约 34px 高的紧凑列表，型号、板型备注、烧录路线、目标存储和适配状态按列对齐。
- 将系列搜索收进列表工具栏，缩小标题、厂商按钮和筛选区间距。
- 使用绿色/灰色标记区分已适配与待适配状态；保留全部型号、原有顺序、选择回调和烧录门禁。
- 同步远端 rc8 的测试改进；保留 Windows/Ubuntu rc8 OTA 清单与公钥。
- 没有修改烧录算法、设备识别或后端执行逻辑。

## 下载和安装

下载 `LYNX-Imager_0.1.0-rc.9_aarch64.dmg`，与 `SHA256SUMS.txt` 核对。确认没有硬件任务正在运行后退出旧应用，打开 DMG，将 **LYNX Imager.app** 拖入 Applications。启动后核对版本 `0.1.0-rc.9`。

本包未公证，macOS 可能阻止打开；仅在确认来源后使用系统提供的安全确认流程，不要关闭全局 Gatekeeper。`.sig` 与 `macos-manual.pub` 沿用已有的独立文件分发密钥，不是 Apple 证书或新的 OTA 信任根。

Windows/Ubuntu 安装包继续使用 [v0.1-rc8](https://github.com/dshanpi/lynx-imager/releases/tag/v0.1-rc8)。本次只上传 macOS 安装候选，不覆盖已有版本。

## 验证边界

构建、测试及打包均在本机执行，GitHub CI 保持停用。界面回归使用隔离模拟 IPC；模拟成功不代表硬件烧录通过。实际结果见附件 `VALIDATION.json` 和 `PACKAGE-CHECK.json`。

未验证：真实烧录/物理回读/冷启动、干净系统安装、旧版本升级、Intel Mac、macOS 26 以下版本、macOS OTA 和 Apple 公证。既有 Rust 格式检查差异另有记录，不声明所有正式发布门禁通过。

附件包含 DMG、分离签名、公钥、SHA-256 清单、验证记录、变更说明及当前原生界面截图。
