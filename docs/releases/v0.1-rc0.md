# LYNX Imager v0.1-rc0

首个公开候选版本，适用于 Windows x64 和 Ubuntu amd64。

## 安装

- **Windows x64** 下载 `LYNX-Imager_0.1.0-rc.0_windows-x64-setup.exe`，运行安装程序。此候选版提供 OTA 签名，Windows 可能显示“未知发布者”。
- **Ubuntu amd64** 下载 `LYNX-Imager_0.1.0-rc.0_linux-amd64.deb`，在下载目录执行 `sudo apt install ./LYNX-Imager_0.1.0-rc.0_linux-amd64.deb`，从应用菜单打开 **LYNX Imager**。

## 烧录与设备工具

- 在「烧录系统」依次选择主控厂商、系列、芯片和存储。可按板名搜索，灰色介质表示当前没有对应烧录路线。
- 「选择系统」支持本地镜像、适配板型的在线资源和最近使用的文件。镜像分析展示可识别的封装、文件指纹和匹配结果。全志按路线选择厂商包、主线镜像和 RAM FES。其他厂商分别使用 Rockchip Loader、UUU、DFU 或 K230 配方。
- 「设备连接」核对设备模式和物理端口。结果页分别显示写入、回读、重启与启动证据。
- 「高级功能」提供原生单板工作台。「连接 AI」提供本机 MCP 和远端 SDK 通道。

## 后续更新

已安装此版的用户可通过启动检查或设置中的「检查更新」获取后续版本。更新器使用 LYNX Imager 独立的 GitHub 清单和签名公钥，为当前平台下载完整安装包。发布标签为 `v0.1-rc0`，应用内版本为 `0.1.0-rc.0`。独立 LYNX 产品使用自己的更新通道。

## 验证范围

Ubuntu 原生桌面模拟运行覆盖 35 个界面状态、454 次操作，包含五个厂商以及写入成功、失败和重试路径。另用 Linux 发布包中的程序检查设置、镜像、任务记录、设备工具和 AI 页面，并用 Linux 伪终端验证实际串口收发及断连。20 项前端测试通过；Rust 测试 717 项通过，6 项忽略。

两个平台的完整包均已通过 Imager 公钥验签。Ubuntu 原生更新器针对两个平台完成候选版本发现、同版本检查、真实包下载和篡改拒绝测试。Windows 安装包经过解包检查，包括 3,545 个资源文件及 OpenixCLI 的已验收 SHA-256。此次设备覆盖采用模拟数据，Windows 原生安装及后续公开版本覆盖升级仍待实测。
