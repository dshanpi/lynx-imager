# LYNX Imager v0.1-rc2

应用版本为 `0.1.0-rc.2`，面向 Windows x64 和 Ubuntu amd64。

- 烧录系统会按芯片、存储、板型和烧录路线记住最近选择的本地镜像。再次进入相同配置时自动恢复路径，F101 主线 SPI NOR 也会恢复对应的 RAM Loader。软件重新读取文件并核对指纹，烧写前仍需确认。
- 选择其他镜像时，文件对话框从上次使用的目录打开。
- 设置保存失败时会恢复 USB 配置。更新检查会记住已跳过的版本，任务记录在读取失败时可重试。
- AI 服务连接测试能识别 HTTP 200 中的错误对象和空回复列表，并显示失败原因。

Windows 使用当前用户安装包，Ubuntu 使用 amd64 Debian 包。更新包沿用 LYNX Imager 的 OTA 签名密钥。
