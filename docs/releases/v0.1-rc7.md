# LYNX Imager v0.1-rc7 · 绿色烧录界面

macOS 26.0+ / Apple Silicon arm64 手动安装预发行版。应用版本为 `0.1.0-rc.7`。本包为 ad-hoc 签名，未 Apple Developer ID 签名及公证，不进入 OTA。

## 本次更新

- 烧录系统采用绿色浅色界面，统一目标选择、系统镜像、设备连接、烧录确认、进度、成功和失败恢复页面。
- 调整厂商/芯片系列筛选、型号与介质卡片、四步导航、固定操作栏和步骤提示。
- 删除筛选栏下重复的厂商/系列介绍和板卡示意图，让型号列表直接接在筛选栏下；介质选择标题保留已选芯片型号。
- 按用户要求移除仓库内旧 UI 设计 Skill 和固定视觉尺寸约束；保留输入安全、IPC、设备操作确认及发布检查。
- 后端烧录业务、设备路线和执行门禁保持原样。高级功能和 AI 工作区没有重新设计。

## 安装

1. 下载 `LYNX-Imager_0.1.0-rc.7_aarch64.dmg` 与 `SHA256SUMS.txt`，核对 SHA-256。
2. 确认没有正在执行的硬件任务，退出旧应用，打开 DMG，将 **LYNX Imager.app** 拖入 Applications。
3. 启动后核对版本 `0.1.0-rc.7`。当前包未公证，macOS 可能阻止打开；仅在确认来源后使用系统提供的安全确认流程，不要全局关闭 Gatekeeper。

`.sig` 和 `macos-manual.pub` 沿用已有的 macOS 手动分发密钥，用于文件校验，不代表 Apple 公证，也不改变 Windows/Linux OTA 信任配置。

## 验证范围

绿色 UI 基线：Imager 测试 20/20 通过；1280×768 和 1090×720 两种尺寸各检查 27 项、41 个界面状态，页面异常为 0；原生 Tauri 窗口检查了目标、介质及镜像路线选择。成功和失败分支使用隔离模拟数据，不是真实烧录结果。

本机补充 Rust supervisor 测试：44 通过、5 项跳过、0 失败。聚合 `verify:changed` 的前端和 IPC 检查通过，但 Rust 格式检查存在基线已有差异；未为 UI 修改扩大后端变更，不宣称所有发布门禁通过。
