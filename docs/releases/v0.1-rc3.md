# LYNX Imager v0.1-rc3

应用版本为 `0.1.0-rc.3`，面向 Windows x64 和 Ubuntu amd64。

- 选择镜像后可直接查看横向分区布局和各区段的大小、位置。覆盖 F101、T113、RK3576、K230、i.MX6ULL 和 STM32MP157 的对应镜像或布局描述。缺少可验证布局时，界面提示所需信息。
- 基础烧录中点击一个 USB 下载口即可选择本次目标。镜像选择页移除了重复的资料核对勾选，写入前仍会检查目标和文件。
- 「设备连接」新增驱动安装。Windows 的全志 FEL、STM32 DFU 和 K230 提供经校验的 Zadig 安装入口，瑞芯微使用厂商 Rockusb INF。i.MX6ULL 的 SDP 使用系统 HID，Fastboot 可按需配置 WinUSB。Ubuntu 可为所选厂商安装 USB 访问规则。
- Imager 在启动硬件操作前检查与原版 LYNX 的占用冲突，安装驱动结束后重新检测下载口。

Windows 安装包和 Ubuntu Debian 包通过 Imager 的 OTA 签名验证。逐板替换驱动后的实物烧录仍待验收。
