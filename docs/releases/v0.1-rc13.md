# LYNX Imager v0.1-rc13

Windows x64 和 Ubuntu amd64 预发行版，应用版本为 `0.1.0-rc.13`。

- Windows 上选择全志芯片后，打开「设备连接 → 安装驱动 → 安装全志 FEL 驱动」，即可安装匹配 `USB\VID_1F3A&PID_EFE8` 的全志驱动。首次使用会下载百问网提供的驱动包并校验 SHA-256，随后由 Windows 请求管理员授权。
- 安装结果会区分驱动已加入驱动库、已绑定到当前 FEL 设备，以及需要重启或检查设备状态。已连接设备使用 `usbUDisc` 且工作正常时，界面才会报告绑定成功。
- Windows 和 Ubuntu 同步 RC12 的 TF/SD 写卡失败恢复。重新扫描后需要重新选择目标卡，写入和校验期间会锁定操作按钮。

安装包、OTA 签名和 SHA-256 校验文件见本页附件。Windows 版首次安装全志驱动需要联网。
