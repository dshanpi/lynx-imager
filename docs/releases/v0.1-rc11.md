# LYNX Imager v0.1-rc11

Windows x64 和 Ubuntu amd64 预发行版，应用版本为 `0.1.0-rc.11`。

- 烧录目标按厂商、系列和型号选择。型号并排展示，共有存储与镜像格式在系列标题旁显示。RK3576 排在 RK35 首位，存储介质由用户选择。
- 全志与瑞芯微型号提供通用 eMMC 入口。DshanPI-A1 配有对应的 RK3576 RAM Loader，其他板型可指定自己的 Loader。
- 支持在应用内选择读卡器，向 TF / SD 卡写入整盘镜像并校验。瑞芯微 eMMC 用户区可按所选 USB 设备单独擦除。
- 镜像选择与确认页使用板型和存储参数展示目标，设备连接、任务状态与诊断记录沿用烧录向导。

从附件安装 Windows EXE 或 Ubuntu DEB，升级前请结束硬件任务并退出程序。安装包附带 OTA 签名与 SHA-256 校验值。模拟烧录测试与安装启动测试不代表每款实物开发板均已复测。
