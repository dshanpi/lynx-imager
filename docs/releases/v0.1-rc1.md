# LYNX Imager v0.1-rc1

候选版本，应用内版本为 `0.1.0-rc.1`。支持 Windows x64 和 Ubuntu amd64。

## 更新内容

- 烧录系统、高级功能和连接 AI 共用应用导航。烧录系统的侧栏宽度与字号对齐高级功能，切换工作区时保留目标上下文。
- 选择系统默认打开本地文件。板型、存储和下载模式集中在标题行。全志厂商路线选择原厂固件包，主线路线分别标明写入 Flash 的文件与加载到 RAM 的引导来源。
- F101 主线 SPI NOR 支持先浏览板型资源并核对镜像和 Loader 指纹，到设备连接步骤再绑定具体设备。预检会复核发布清单、文件及目标设备身份。

## 安装与升级

RC0 用户可在设置中检查更新。Windows 使用当前用户安装包，Ubuntu 使用 amd64 Debian 包。两个安装包均使用 LYNX Imager 的 OTA 密钥签名。本次 Windows 包仅做 OTA 签名，系统可能显示未知发布者。

## 验证范围

Ubuntu 使用原生桌面、模拟设备和伪终端验收。Windows 验收范围为安装包解包、内置资源及更新签名检查。Windows 原生安装、覆盖升级与实际板卡烧写由使用者另行验收。
