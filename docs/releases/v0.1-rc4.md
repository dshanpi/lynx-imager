# LYNX Imager v0.1-rc4

此预发行版适用于 Windows x64 和 Ubuntu amd64，应用版本为 `0.1.0-rc.4`。

- 精简安装包，移除默认随包分发的 Python 解释器。烧录 Linux 单板和使用随包的 OpenOCD 均可直接运行。
- 保留 MCU 工作台、CMSIS-DAP、OpenOCD、pyOCD、J-Link、ST-Link 及 MCU AI 网关。
- 使用 pyOCD 调试或烧写瑞萨 RA 时，请安装外部 pyOCD 并提供对应的 CMSIS-Pack。Imager 可在系统路径中查找 pyOCD，也可使用手动选择的可执行文件。

两个平台提供完整安装包和独立 OTA 签名。此轮验收覆盖软件回归和模拟设备流程，逐板实物烧录和 Windows 原生覆盖升级仍待实机验收。
