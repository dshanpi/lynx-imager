# LYNX Imager v0.1-rc12 · macOS 同步与写卡恢复

适用于 **macOS 26.0+、Apple Silicon arm64**，应用版本 `0.1.0-rc.12`。手动安装预发行版，采用 ad-hoc 应用签名与独立分发文件签名；未 Apple Developer ID 签名和公证，不进入 macOS OTA。

## 本次变化

- 同步最新 `main` 的 rc11 代码：厂商／系列／型号选择、TF/SD 读卡器整盘镜像写入、瑞芯微 eMMC 擦除、内置 RK3576 RAM Loader、镜像历史与输入焦点修复。
- 沿用远端新版紧凑系列列表、统一主题和共享标题尺寸，没有恢复早期的大块型号卡片或重复系列说明区。
- 修复读卡器写入过程中仍显示“确认写卡”的误导状态，改为“正在写卡与校验”。
- 写卡异常显示具体原因、部分写入提示和恢复入口。失败后重新检测存储卡并手动重选，不直接沿用旧目标重试。
- 新增进行中按钮锁定、失败不显示成功、重新扫描清除旧选择和超长设备名称的交互回归。
- 本轮未改变底层写入、擦除和设备识别算法；Windows／Ubuntu rc11 安装包和 OTA 更新源保持原样。

## 安装

1. 下载 `LYNX-Imager_0.1.0-rc.12_aarch64.dmg`，核对附件 `SHA256SUMS.txt`。
2. 确认没有硬件任务运行，退出旧应用。打开 DMG，将 **LYNX Imager.app** 拖入 Applications。
3. 启动后核对版本 `0.1.0-rc.12`。本包尚未公证，系统可能要求通过“隐私与安全性”确认来源；不要关闭全局 Gatekeeper。

`.sig` 和 `macos-manual.pub` 沿用已有 macOS 独立分发密钥，不是 Apple 证书，也不是 Windows/Linux OTA 信任根。

## 本轮验证

- Rust：727 通过、6 项忽略、0 失败。
- Imager 前端测试：20/20；发布资产及分离签名测试：5/5。
- 类型检查、ESLint（0 error）、前端格式、IPC（388 个命令／33 个事件）、生产前端与 macOS 原生构建通过。
- 1090×720 和 1280×768：各 30 项交互检查、53 个页面状态；包含失败、扫描异常、取消、重复操作、焦点、长文本和配置保存。未发现横向溢出或页面脚本错误。
- 打包后的真实 Tauri 窗口已启动，核对版本、目标／介质选择、本地文件解析与 SHA-256、只读读卡器扫描、高级功能、未连接串口／SSH、AI 配置、设置和任务记录。
- DMG 挂载、16 项 Mach-O 依赖检查、ad-hoc 签名和挂载后程序摘要通过。具体范围见 `VALIDATION.json`、`PACKAGE-CHECK.json`。

`UI-VERIFICATION.zip` 的自动化截图使用隔离模拟 IPC，图中的设备、进度和成功结果不是实机证据；夹具显示 rc11 版本，实际发布包为 rc12。原生首页截图另见 `UI-macOS-rc12.png`。
