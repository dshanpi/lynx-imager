# LYNX Imager v0.1-rc8

此预发行版面向 Windows x64 和 Ubuntu amd64，应用版本为 `0.1.0-rc.8`。

- 烧录工作区采用绿色浅色主题，覆盖目标选择、镜像选择、设备连接、烧录进度和结果页。
- 按 Ctrl+K 可搜索芯片或板名。选好可用介质即可进入镜像页，页面会列出当前路线需要的镜像和引导文件。
- Windows 使用当前用户 NSIS 安装包，Ubuntu 使用 Debian 安装包。两个平台沿用现有 OTA 公钥，升级前会校验安装包签名。

发布附件包括两个安装包、各自的 OTA 签名、更新清单和 SHA-256 校验文件。验证范围包含桌面安装与软件流程，逐板硬件烧写需另行实测。
