# LYNX Imager v0.1-rc10

Windows x64 和 Ubuntu amd64 预发行版，应用版本为 `0.1.0-rc.10`。

烧录目标页采用紧凑的芯片型号列表。板型、烧录路线、目标存储和适配状态按列排列，可搜索系列内型号，选择支持的介质后继续。此版本沿用 RC8 的烧录和设备识别逻辑。

Windows 使用当前用户 EXE 安装包，Ubuntu 使用 DEB 安装包。升级前请先结束正在运行的硬件任务并关闭程序。两个安装包使用现有 OTA 密钥签名，文件摘要见附件 `SHA256SUMS.txt`。macOS 用户可使用 [RC9](https://github.com/dshanpi/lynx-imager/releases/tag/v0.1-rc9)。

验证范围为安装升级、原生窗口操作、模拟烧录流程和 OTA。逐板实物烧写另行验收。
