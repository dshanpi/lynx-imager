# LYNX Imager v0.1-rc5

此预发行版适用于 Windows x64 和 Ubuntu amd64，应用版本为 `0.1.0-rc.5`。

- 基础烧录选好芯片和目标存储即可进入「选择系统」。RK3576、i.MX6ULL、STM32MP157、K230 等型号的具体板名改为选填。
- 从「最近使用」选择镜像时，同时恢复对应的 RAM Loader。全志厂商系统和主线系统分别记忆文件。T153 参考清单支持 Omnigate T153 板名。
- F101 的 YuzukiNeko XIP 配置支持将 Zephyr 应用 BIN 与配套启动段合成为 SPI NOR 镜像。选中应用后，点击「选择启动来源并合成」，提供匹配的 `xip-boot_spi.bin` 或带该启动段的整片镜像。设备连接前仍需选择配套的 RAM FES 引导包。
- RK Loader 无法读取、STM32 DFU 接口不匹配、NXP 缺少板级 UUU 配方时，页面会显示具体原因。USB 热插拔监听失败后可点击「重新检测设备」恢复。

附件包含两个平台的完整安装包、OTA 签名和 SHA-256 校验文件。本版验证覆盖软件流程和模拟设备。逐板实物烧写及 Windows 原生覆盖安装仍待实机验收。
