# LYNX Imager (V5) HTML UI 原型

本目录包含依据 LYNX Imager V5 设计需求包渲染的纯前端交互式 HTML UI 原型，无需任何外部网络资源或构建工具。

## 文件说明

- `index.html`：入口页面，支持直接双击（`file://`）在现代浏览器中离线打开。
- `styles.css`：V5 设计系统样式表（含浅色 / 深色 / 跟随系统主题、减弱动效支持、`1536×1024` 桌面端比例与 `<1100px` 自适应详情折叠）。
- `app.js`：全部 **17 张 V5 页面**（`B01`–`B09`、`A01`–`A03`、`C01`–`C03`、`S01`–`S02`）的规范状态预设、状态流转与安全校验交互逻辑。

## 使用方法

1. 在浏览器中直接打开 `index.html`（默认进入 `B01 · 选择开发板`）。
2. 使用顶部黑色原型工具栏可一键切换任意页面（`B01`–`S02`）、在 **1536×1024 画布 / 自适应铺满 / 17 页画廊** 之间切换，或按 `H` 键开启/退出 **纯享模式**。
3. 也可直接在页面内按正常业务流程交互操作：
   - **基础烧录**：选板（`RK3588 系列` 需展开并选择具体型号）→ 选系统 / 拖入本地文件 → 检查 USB 接口与必填 Loader → 右侧确认抽屉（默认未勾选）→ 模拟进度 / 结果 / 失败恢复。
   - **高级烧录**：支持 F101 SPI NOR 与 RK3588 eMMC 工作台配置、缺少必填 Loader 预检定位。
   - **连接 AI**：支持本机 MCP 配置标签页与剪贴板复制、远端失败隔离状态、AI 请求单次确认抽屉。
   - **共享页面**：支持任务记录筛选、`S02` 设置页实时浅色/深色主题与动效切换。
