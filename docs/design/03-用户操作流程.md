# 用户操作流程

## 1. 普通用户烧录全志设备

1. 打开软件，默认进入基础烧录。
2. 在左侧第 1 步选择具体板型，例如 `T113-Pro`。
3. 进入第 2 步，选择板型资源或点击“本地文件”。
4. 拖入或选择镜像文件，等待读取结果。
5. 查看右侧镜像信息，确认格式和适用板型来源。
6. 进入第 3 步，连接 USB，等待 LYNX 发现 FEL 设备。
7. 选择实际 USB 设备，核对板型绑定和检测模式。
8. 点击“检查并烧录”，等待只读预检。
9. 在右侧确认抽屉中核对设备、镜像、路线、校验和结束动作。
10. 勾选“我已核对设备，并备份重要数据”。
11. 点击“确认烧录”。
12. 等待准备、擦除、写入、校验和结束动作完成。
13. 在结果页分别查看写入、校验、重启和系统启动状态。
14. 通过开发板屏幕、串口或其他有效证据确认系统启动。

## 2. 普通用户烧录 RK 设备

1. 选择具体 RK 板型，不把“RK3588 系列”当作最终设备。
2. 选择板型镜像或本地镜像。
3. 连接设备并进入 Loader 或 Maskrom。
4. 等待 LYNX 识别设备模式。
5. 如果当前路线要求 RAM Loader，选择匹配具体板型的文件。
6. Loader 缺失时，主操作按钮保持禁用。
7. 文件齐全后运行预检，确认目标存储和完整擦除警告。
8. 通过确认抽屉后开始烧录。

## 3. 专业用户使用高级烧录

1. 顶部切换到“高级烧录”。
2. 在目标设备栏选择已发现的设备。
3. 选择现有平台、烧录路线和目标存储。
4. 提供镜像、组件和所需 Loader。
5. 配置后执行动作、校验和结束动作。
6. 点击“运行预检”。
7. 按右侧问题清单补齐缺失项。
8. 预检通过后复用统一确认抽屉。
9. 执行任务并查看阶段日志。

## 4. 配置 AI 工具

1. 顶部切换到“连接 AI”。
2. 在“本机通道”选择客户端，例如 Codex 或 ZCode。
3. 复制当前运行状态提供的 MCP 地址和客户端配置。
4. 在外部客户端完成配置。
5. 回到 LYNX 点击“检查服务”。
6. 分别确认本机服务可用和客户端会话状态。
7. AI 发起烧录时，在“调用记录”打开待确认请求。
8. 核对目标设备、镜像指纹、路线和动作。
9. 勾选本次确认后允许执行；拒绝则请求失效。

## 5. 失败恢复

1. 查看失败阶段：预检、擦除、写入、校验或结束动作。
2. 阅读主区域给出的下一步操作。
3. 检查 USB、供电、设备模式和必要文件。
4. 点击“重新检测设备”。
5. 设备身份变化后重新确认目标。
6. 不自动重复擦写，不把失败任务标记为成功。
7. 通过“导出诊断记录”保存任务上下文和错误信息。
