# 功能分类与页面职责

## 1. 功能分类

| 分类 | 功能 | 所属工作区 |
|---|---|---|
| 板型 | 搜索、厂商筛选、具体板型选择 | 基础 |
| 镜像 | 板型资源、本地文件、拖入、最近使用 | 基础 |
| 接口 | USB 扫描、设备绑定、FEL/Maskrom/Loader 识别 | 基础、高级 |
| 文件 | 镜像、组件、RAM Loader、RAM FES Loader | 基础、高级 |
| 预检 | 文件读取、能力匹配、目标检查、布局检查 | 基础、高级 |
| 执行 | 准备、擦除、写入、校验、回读、结束动作 | 基础、高级 |
| 结果 | 写入、校验、重启、启动分开记录 | 基础、高级、AI |
| 专业配置 | 路线、存储、参数、执行计划、日志 | 高级 |
| AI 通道 | MCP 地址、客户端配置、连接状态、调用记录 | 连接 AI |
| 记录 | 报告、日志、任务筛选、导出 | 共享 |
| 设置 | 语言、外观、动效、更新、诊断 | 共享 |

## 2. 页面职责

### 基础烧录

| 页面 | 主要内容 | 主要按钮 |
|---|---|---|
| 选择板子 | 搜索与板型列表 | 下一步：选择系统 |
| 板型系统 | 板型资源和本地文件入口 | 获取并继续 |
| 本地镜像 | 文件读取和镜像信息 | 下一步：配置接口 |
| 接口就绪 | USB 设备和模式 | 检查并烧录 |
| RK 缺少 Loader | 必填 Loader | 选择文件 |
| 烧录确认 | 覆盖警告和本次参数 | 确认烧录 |
| 写入进度 | 阶段、速度、日志 | 等待完成 |
| 完成结果 | 四类独立结果 | 烧录另一块板 |
| 失败恢复 | 错误阶段和恢复建议 | 重新检测设备 |

### 高级烧录

| 页面 | 主要内容 |
|---|---|
| SPI NOR 工作台 | 完整镜像、RAM FES Loader、物理备份和回读计划 |
| RK 工作台 | 当前 Loader、eMMC、完整擦除和校验 |
| 预检问题 | 问题清单与定位输入项 |

### 连接 AI

| 页面 | 主要内容 |
|---|---|
| 本机通道 | 客户端配置、本机地址、复制和连接检查 |
| 远端通道 | Windows 本机与远端 SDK 通道分开显示 |
| 请求确认 | AI 调用记录和本次烧录授权 |

## 3. 现有后端路线的展示约束

- 全志厂家镜像：展示厂家镜像和当前支持的结束动作。
- 全志主线 NAND：展示组件路线，不能伪装成任意 raw 镜像。
- 全志 eMMC：保留现有 Boot0 和目标存储语义。
- 全志 SPI NOR：保留 RAM FES Loader、物理地址、物理布局保护和独立回读。
- Rockchip 厂家包：展示现有厂家包能力。
- Rockchip 完整 eMMC：展示当前 Loader 会话和完整擦除警告。

界面统一不代表后端路线统一，任何选项必须由真实能力数据驱动。
