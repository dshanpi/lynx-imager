# 验收标准与交付边界

## 1. 基础烧录验收

- [ ] 默认进入基础烧录。
- [ ] 左侧只显示四步：选择板子、选择系统、配置接口、烧写系统。
- [ ] 每一步主操作唯一且清晰。
- [ ] 选板后可以在不连接 USB 的情况下继续选择系统。
- [ ] 本地文件可以拖入或通过文件选择器导入。
- [ ] 文件读取成功和板型适配状态分开显示。
- [ ] FEL、Maskrom、Loader 等模式来自检测结果并以只读形式展示。
- [ ] 多台设备时用户必须明确选择目标。
- [ ] 烧录前确认默认未勾选，未确认时按钮不可用。
- [ ] 进度页区分准备、擦除、写入、校验和结束动作。
- [ ] 结果页区分写入、校验、重启和启动状态。
- [ ] 失败后不会自动重试破坏性动作。

## 2. 高级烧录验收

- [ ] 可以在一个工作台中查看目标设备、镜像、Loader、存储和执行参数。
- [ ] 只展示当前后端能力支持的路线和参数。
- [ ] SPI NOR 路线保留物理布局、RAM FES Loader 和独立回读约束。
- [ ] NAND 和 eMMC 不因统一 UI 被切换到错误路线。
- [ ] 缺少必填 Loader 时运行预检和开始烧录按钮不可用。
- [ ] 预检未通过时明确显示“尚未开始擦写”。
- [ ] 高级模式仍使用统一确认和结果页面。

## 3. AI 连接验收

- [ ] 本机服务、AI 客户端会话和远端隧道分别显示状态。
- [ ] 地址端口来自当前运行状态。
- [ ] 本机和远端地址有独立复制动作。
- [ ] 连接失败时不展示过期或猜测地址。
- [ ] AI 请求显示设备、镜像指纹、路线和动作。
- [ ] 未勾选本次确认时不能执行写入。
- [ ] AI 调用不能绕过手动流程的设备互斥和后端保护。

## 4. 视觉与可访问性验收

- [ ] 左侧基础导航约占 15%–16%，主内容区域明显大于导航。
- [ ] 三个工作区顶栏、字体、按钮和状态颜色一致。
- [ ] 200% 缩放或窄窗口下文字不被截断，主操作仍可见。
- [ ] 键盘 Tab 顺序与视觉顺序一致。
- [ ] Enter 执行普通下一步，不直接绕过破坏性确认。
- [ ] Escape 关闭未执行的抽屉并恢复焦点。
- [ ] 状态不只依靠颜色区分，同时显示文字和图标。
- [ ] 支持减少动态效果设置。

## 5. 交付边界

本需求包包含：

- Markdown 需求文档
- 17 张静态 UI 效果图
- 页面索引和提示词
- 文件清单与 SHA-256

本需求包不包含：

- 产品代码修改
- Windows 安装包
- 后端协议变更
- 实机烧录验收
- 在线固件目录发布

后续实现必须以现有 OpenixCLI 和 LYNX 烧录能力为准，不能仅根据效果图新增未经验证的功能。
