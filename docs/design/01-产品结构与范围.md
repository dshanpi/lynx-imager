# 产品结构与范围

## 1. 产品目标

LYNX Imager 的开源版只聚焦两件事：

1. 让用户容易理解并使用 SoC 系统镜像烧录。
2. 让外部 AI 工具能够通过 MCP 安全调用设备检查和烧录能力。

现有厂家烧录、主线系统、NAND、eMMC、SPI NOR、FEL、Maskrom、Loader、物理回读和保护逻辑继续由现有后端实现负责。此次需求调整的是使用交互、页面组织和任务编排展示。

## 2. 三个工作区

### 基础烧录

默认进入。左侧显示四步：

1. 选择板子
2. 选择系统
3. 配置接口
4. 烧写系统

烧录前确认使用右侧抽屉，不单独增加第五个步骤。

### 高级烧录

用于专业用户集中配置：

- 目标设备和 USB 身份
- 平台与烧录路线
- 系统镜像与组件文件
- RAM Loader 或 RAM FES Loader
- 目标存储、校验和结束动作
- 预检结果、执行计划、日志和诊断

高级模式不新增未经后端支持的写入能力。

### 连接 AI

用于：

- 选择 AI 客户端适配方式
- 查看当前运行的本机 MCP 地址
- 复制客户端配置
- 分别查看本机服务、客户端会话和远端隧道状态
- 查看待确认请求和调用记录

AI 不提供聊天首页、模型商店、API Key 输入或绕过确认的永久授权。

## 3. 全局布局

| 区域 | 建议比例 | 职责 |
|---|---:|---|
| 顶部工作区导航 | 68px | 基础烧录、高级烧录、连接 AI |
| 左侧导航 | 约 240px | 当前工作区的步骤或功能菜单 |
| 主操作区 | 约 65%–70% | 当前页面主要操作 |
| 详情区 | 约 30%–35% | 当前选择、预检、执行计划 |
| 底部操作栏 | 76px | 返回、状态、唯一主操作 |

窗口缩窄时详情区收为可展开摘要，不缩小正文到不可读尺寸。

## 4. 不在本次范围内

- 不重写现有 OpenixCLI 协议和存储处理。
- 不把所有芯片视为可互换板型。
- 不新增任意地址、任意分区或跳过保护的入口。
- 不把在线资源目录当作唯一镜像来源。
- 不把 100% 烧录进度显示为系统已经启动。
- 不因 AI 接入而放宽设备、镜像、参数或重启授权。
