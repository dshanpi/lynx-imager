# 状态异常与安全规则

## 1. 状态分层

| 状态 | 含义 | 允许写入 |
|---|---|---:|
| 未选择 | 缺少板子、镜像或目标 | 否 |
| 已读取 | 文件可以打开或读取 | 否，仍需检查适配 |
| 已发现 | 发现 USB 设备或 Loader | 否，仍需绑定和预检 |
| 预检通过 | 当前组合满足可执行条件 | 否，仍需确认覆盖 |
| 待确认 | 用户需要确认本次破坏性动作 | 否 |
| 执行中 | 后端正在改变设备 | 任务锁定 |
| 写入完成 | 写入动作结束 | 不代表启动 |
| 校验通过 | 指定类型的校验通过 | 不代表启动 |
| 重启完成 | 重启命令执行或返回成功 | 不代表系统启动 |
| 启动待确认 | 尚无启动证据 | 不得显示启动成功 |
| 失败 | 某阶段失败 | 否，需恢复后重新确认 |

## 2. 必须分开的结果

1. 镜像写入
2. 协议或回读校验
3. 物理位置或布局验证
4. 重启指令
5. 板卡实际启动

一个阶段的成功不能自动替代另一个阶段的证据。

## 3. 常见异常

| 异常 | 页面反馈 | 处理方式 |
|---|---|---|
| 未发现设备 | 显示接口和模式说明 | 重新检测，不自动重启 |
| 发现多台设备 | 列出 USB 身份 | 用户明确选择，禁止按扫描顺序写入 |
| 模式不匹配 | 显示检测到的只读模式 | 按板型说明重新进入模式 |
| Loader 缺失 | 输入项橙色提示，主按钮禁用 | 选择匹配文件 |
| 文件不可读 | 原位显示原因 | 重新选择或拖入文件 |
| 文件可读但兼容性未知 | 明确显示待核对 | 核对来源或进入预检 |
| 预检失败 | 右侧问题清单和定位链接 | 修正后重新预检 |
| 写入中断 | 显示失败阶段和可能影响 | 检查连接，重新检测并确认 |
| 校验失败 | 不执行结束动作 | 导出日志，重新确认后重试 |
| 远端通道失败 | 本机和远端状态分开 | 不显示未验证地址，重新连接 |

## 4. 破坏性动作保护

- 擦除、写入、重启必须属于同一个本次任务参数快照。
- 目标设备、镜像文件指纹、路线、存储和结束动作改变后，旧确认失效。
- AI 请求与手动任务使用同一确认模型。
- 不提供“永久允许所有擦写”。
- 写入或校验失败时不得执行预定重启。
- 任务执行中锁定会改变设备和参数的操作。
- 关闭窗口、切换工作区或断开连接时，展示任务锁定状态。

## 5. 地址与通道

- 本机 MCP 地址必须从当前运行状态读取，不能写死端口。
- `127.0.0.1` 只表示当前运行服务的电脑。
- Windows 本机 MCP 与远端 SDK 隧道独立显示地址、状态和复制按钮。
- HTTP 健康不等于 AI 客户端已建立会话。
- 远端地址未验证时不提供可复制的旧地址。
