# IMAGER-MAC-001：全页面布局复核与 macOS 交付

日期：2026-11-24。起点 main 2b6658e8e478ef9386bfdd3124d24814de6c6229，首次克隆，无用户本地改动。

## 范围与固定边界

- 保留烧录系统、高级功能、连接 AI 三工作区；原 LYNX 浅深主题、264/232 px 左栏、44 px 导航、32 px 控件、24 px 状态栏为设计基线。
- 覆盖目标/介质、系统镜像与布局、设备连接、写入确认/进度/失败/成功、记录/驱动、概览/串口/SSH/固件/AI 通道、六个 AI 页面与设置。
- 修复布局、尺寸、长内容、滚动、焦点和按钮可见性；不改写烧录协议、授权、目标绑定、验签或安全门禁。模拟数据仅用于隔离验收。
- 1090×720、1280×768、1440×900、1920×1080；浅深主题分别检查。浏览器回归与原生 macOS 窗口证据分别报告。
- 本任务只修改 lynx-imager。不得复制私有 LYNX 源码或修改官网/.17。此仓库本身为公开 GPL 项目，按其自身发布规范交付。

## 已发现的基线问题

1. `npm run test:imager` 使用 `node --test tests/imager`，Node 24 报 MODULE_NOT_FOUND；明确 glob 才能执行实际用例。
2. macOS 手动打包脚本仍命名 LYNX.app/LYNX_xxx.dmg，存在与原版混淆风险。
3. macOS 签名身份 0；GitHub 上传认证可用。OTA 生成/发布脚本仅支持 Windows+Linux，不能假装已支持 macOS 更新。

## 验收标准

- 每个页面有实际截图和操作结果；不以根节点无滚动推断内部无裁切。主要操作与焦点可见，长路径可查看完整内容，窄窗口内部有界滚动。
- 浅深色角色沿用 tokens，不把原页面替换成独立网页原型。
- 测试入口确实执行测试；macOS 包名、bundle ID、可执行文件与 Imager 一致，资源/架构/依赖/摘要经过检查。
- 发布使用新版本/标签，保留旧资产。签名、OTA、安装、硬件项如缺证据必须报告；不能把临时签名包标成公证正式版。
