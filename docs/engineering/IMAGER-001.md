# IMAGER-001：基础烧录向导接入现有后端

## 用户价值

普通用户可以在一个连续流程里选择开发板、选择镜像、绑定已保存设备，并在一次明确确认后提交烧录任务；专业用户和 AI 工具仍通过既有工作台进入，不产生第二套烧录协议。

## 范围

- 基础工作区：四步向导和板型选择。
- 支持示例路线：全志厂家镜像、全志 SPI NOR 主线、RK3588 eMMC 主线。
- 只读设备读取：调用 `workbench_list_devices`，按芯片厂商过滤已保存设备。
- 烧录提交：调用 `workbench_start_flash`，保留 Loader、路线、校验和烧后重启参数。
- 任务状态：订阅 `workbench-task-event`，展示任务 ID 和终态。

## 明确不在范围内

- 不复制或改写 OpenixCLI、FEL/FES、NAND、eMMC 和 SPI NOR 底层协议。
- 不在前端模拟设备在线、烧录成功或系统启动成功。
- 不自动扫描并选择其他 USB 设备，不自动重试失败任务。
- 不把高级工作台或 AI 监督器的逻辑复制进基础向导。

## Given / When / Then

### IMAGER-001-A：路线选择

- Given 用户选择 F101，When 进入系统步骤，Then 路线固定为 `mainline_spinor`，并要求匹配 Loader。
- Given 用户选择 T113-Pro，When 进入系统步骤，Then 使用厂家镜像路线，不附加 SPI NOR 或 eMMC 参数。
- Given 用户选择 RK3588，When 进入系统步骤，Then 路线固定为 `mainline_emmc`，并要求匹配 Loader。

### IMAGER-001-B：设备作用域

- 用户点击检测后，列出当前烧录工具发现的 USB 端口。单击一行即选中本次目标，切换行只保留最后一次选择。完整 USB 路径可在连接详情展开。
- 文件校验通过即可进入设备连接。对未保存的端口，基础烧录在预检时建立内部任务目标，高级功能的单板列表仅显示用户保存的配置。
- 重新检测后须重新点选目标。预检及提交前按同一物理端口、设备标识和模式复核，目标断开时退回设备连接。

### IMAGER-001-C：高风险动作

- Given 用户未勾选确认框，When 点击开始烧写，Then 前端不调用 `workbench_start_flash`。
- Given 用户已确认且存在设备、镜像和 Loader，When 提交任务，Then 参数包含 `verify: true` 和 `postFlashAction: reboot`，失败不自动重试。
- Given 后端返回任务事件，When 状态变化，Then 界面展示任务状态；协议进度不被解释为启动成功。

### IMAGER-001-D 双应用共存验收

- 同时打开原版 LYNX 和 Imager，切换单板、选择镜像、离开再返回串口页。记录原版进程和已连接串口的收发情况，确认 Imager 只在用户明确连接时打开串口。
- 保持原版打开，在 Imager 提交烧写。检查后端返回 `LEGACY_LYNX_ACTIVE`，没有启动烧录子进程。原版任务和窗口应可继续使用。
- 用独立进程模拟一个占用中的烧录器，在 Imager 检测同类设备。应返回 `FLASHER_IN_USE`，模拟进程继续运行。该进程退出后，用户手动重新检测可以继续。
- 原版运行期间，在 Imager 连接 CH347 电源控制器。应在调用驱动前返回 `CH347_OWNER_UNKNOWN`。启动 Imager 本身不应打开监视会话。
- 使用无硬件任务的隔离进程核对 Windows 安装、卸载与升级。原版应用和原版目录中的同名辅助程序均应继续运行。通过实际构建的安装包核对可执行文件及烧录器指纹。

此保护由 Imager 执行。若 Imager 已开始写入，之后才启动的原版 LYNX 仍可独立访问硬件。验收时用模拟进程覆盖并发请求，避免在真板上同时写入。

### IMAGER-001-E 镜像布局验收

- 在选择系统页打开文件后自动显示布局，移除文件时同步清空。横条和明细表使用相同的名称、颜色与字节数。包内偏移、磁盘偏移和 DFU 目标地址分别标注。
- F101 以本次写入文件的长度绘制 SPI NOR 范围。通过 eGON 校验可确定启动段长度，匹配当前镜像指纹的清单可补充参数和应用起点。清单仅声明起点时，大小显示为“未声明”。单独的 RAM FES 引导包只出现在引导来源栏。
- T113 可切换 sunxi 分区表和 IMAGEWTY 包目录。RK3576 支持经典 RKAF 包目录和整盘分区表。K230 展示 KDImage 分区分配大小。i.MX6ULL 可切换 UUU 文件引用和引用镜像的磁盘分区表。STM32MP157 按 DfuSe Alternate 展示元素地址及长度。
- 使用 `scripts/verify-imager-flash-simulation layouts` 在 Ubuntu 原生窗口验证六种目标。测试包含 512 B 与 4 KiB 扇区 GPT、损坏校验和、截断目录和移除文件。USB 和写入使用模拟后端，镜像检查使用实际 Rust 命令。

## 受保护边界

底层硬件安全门禁、固定板卡作用域、Linux/MCU 隔离、凭据保护、AI 策略和历史 Workbench 行为保持不变。真实桌面启动、Rust 编译、硬件在环和 Windows 安装尚未由本次迁移自动证明。
